# DevSecOps Learning Path

Ce dépôt documente ma progression et les compétences acquises en suivant la documentation et les tutoriels de Stéphane Robert (https://blog.stephane-robert.info/docs/).

## Objectif

L'objectif de ce projet est de mettre en pratique les concepts fondamentaux de l'administration système, de la conteneurisation et de la culture DevOps. Chaque répertoire de ce dépôt représente une étape de montée en compétence technique.

## Compétences acquises

En m'appuyant sur les ressources consultées, j'ai pu travailler sur les piliers suivants :

* Administration système Linux : Maîtrise des commandes, gestion des utilisateurs, des permissions et automatisation.
* Conteneurisation : Création et gestion de conteneurs, écriture de Dockerfiles et orchestration avec Docker Compose.
* Infrastructure as Code : Automatisation du déploiement et configuration d'outils avec Ansible.
* CI/CD : Mise en place de pipelines pour automatiser les tests et le déploiement.
* Observabilité et Sécurité : Mise en œuvre de solutions de surveillance et bonnes pratiques de sécurisation des systèmes.
